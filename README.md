# Quantigration RMA Database
## About This Project

This project demonstrates my experience using MySQL and SQL to create, manage, and analyze a relational database.

The database was designed to manage customer information, orders, and Return Merchandise Authorization (RMA) records.

The project allowed me to practice working with real-world-style business data and using SQL to answer questions that could help a company make better decisions.

## Technologies Used
- MySQL
- SQL
- Relational Databases
- CSV Data
- Database Management
## Database Structure

The database contains three main tables:

- Customers - Stores customer information.
- Orders - Stores customer order and product information.
- RMA - Stores product return information associated with orders.

Primary and foreign keys were used to establish relationships between the tables.

## SQL Skills Demonstrated

During this project, I used SQL to:

- Create a database and tables
- Create primary and foreign keys
- Import data from CSV files
- Retrieve records using SELECT
- Filter records using WHERE
- Connect multiple tables using INNER JOIN
- Analyze data using COUNT
- Organize results using GROUP BY and ORDER BY
- Update existing records using UPDATE
- Delete records using DELETE
- Analyze sales and product returns
- Export query results
## Data Analysis

I used SQL queries to examine sales and return information and identify patterns within the data.

This included analyzing customer orders, product returns, and return activity by geographic location.

The goal was to turn database records into information that could be understood and used by nontechnical stakeholders.

I also gained hands-on experience troubleshooting SQL errors, working with larger datasets, and writing queries that retrieve useful information from multiple related tables.
